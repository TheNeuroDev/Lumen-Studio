# 🌟 Lumen-Studio

**Your Personal AI Dashboard. Anywhere, Anytime.**

Lumen-Studio bridges the gap between powerful AI capabilities and everyday usability. Designed for privacy and flexibility, it allows you to interact with AI models and manage multimedia content across all your devices.

## ✨ What Can You Do?

*   💬 **Chat**: Interact with AI assistants.
*   💻 **Code**: Generate, debug, and analyze code.
*   🖼️ **Images**: Generate and edit visuals.
*   🎥 **Videos**: Create and process video content.
*   🎵 **Music**: Generate audio tracks.
*   🎙️ **Voice**: Text-to-speech and voice interaction.

## 🔌 Connectivity Options

| Mode | Description |
| :--- | :--- |
| **Fully Offline** | Bring your own uncensored models. Perform processing and store files locally. **Zero internet required.** |
| **API Ready** | Easily configure API keys to connect to cloud-based models. |

## 📱 Access Anywhere via Tailscale

Lumen-Studio is designed to be accessed securely from any device on your Tailscale network.

*   **Encrypted VPN**: All traffic is routed through your private Tailscale network.
*   **Cross-Device**: Works seamlessly on Laptop, Phone, and Tablet.
*   **No Port Forwarding**: Access your dashboard from anywhere without complex network configuration.
